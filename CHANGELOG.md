# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- `#[dyn_shim_foreign]` to generate a shim for a trait defined in another crate,
  where the source trait cannot be re-emitted.
- Reflexive impls (`#[dyn_shim(reflexive = bare)]` / `reflexive = boxed`, and
  both at once) that implement the source trait for the shim's own trait
  objects, so an erased value still satisfies the source trait.
- Standalone `DynClone` and `DynHash` shims, behind the `dyn_clone` and
  `dyn_hash` features, usable as near drop-in replacements for the `dyn-clone`
  and `dyn-hash` crates. The crate was split into a facade over the
  `dyn_shim_macros` proc-macro crate to ship them.
- `#[dyn_shim_bind(Carrier)]` mounts a carrier capability (`DynClone`,
  `DynHash`, or any `#[dyn_shim]` shim's source trait) onto a trait object that
  cannot list it as a supertrait, including onto a different principal that
  inherits the shim.
- `#[dyn_shim(erase)]` keeps a method that is non-dyn-compatible only because of
  a generic type parameter or argument-position `impl Trait` (bounded by a
  single trait, used behind a reference) by lowering the parameter to a trait
  object, e.g. `&mut impl Write` -> `&mut dyn Write`.
- `#[dyn_shim(boxed)]` dispatches a `-> Self` builder by making the shim method
  return `Box<dyn Shim>`, so consuming and chaining builders keep working
  through an erased value.
- `#[dyn_shim(stub = <expr>)]` supplies a custom fallback body for a method that
  cannot forward in a reflexive impl, so it can degrade to a value instead of
  aborting. `#[dyn_shim(panic)]` is sugar for the no-expression case.
- Omission of a `where Self: Sized` method from a `reflexive = bare` impl, so
  calling it on a `&dyn` is a compile error rather than a runtime panic.
- Provided (default-bodied) methods on a `#[dyn_shim_foreign]` shim: the body is
  emitted on the shim trait and computed from forwarded methods, adding a
  convenience method the foreign trait does not declare.
- A Miri CI job covering the unsafe `__clone_box` path.

## [0.2.0] - 2026-06-12

### Added

- Recognition of a bare `Clone` or `Hash` bound on the shim. Instead of passing
  it through as a supertrait (which a dyn-compatible trait cannot have), the
  macro generates the machinery to implement it for the shim's trait objects:
  `Clone` and `ToOwned` for `Box<dyn Shim>`, and `Hash` for `dyn Shim`. Auto
  traits listed alongside select which `dyn Shim + markers` combinations receive
  that machinery.
- Targeted rejection of recognized-but-unsupportable std bounds (`Copy`,
  `Sized`, `Default`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`) with an error at
  the attribute rather than a confusing downstream rustc error.

## [0.1.1] - 2026-06-10

### Added

- Opt-in supertraits on the shim, written like a trait's bounds on the shim
  name, to keep auto-trait bounds such as `Send` on the trait object or reach a
  dyn-compatible supertrait's methods through the shim.
- Validation of `#[dyn_shim]` helper attributes.

### Changed

- The shim preserves each method's full signature and attributes.
- An explicit `self: Self` receiver is treated as by-value.

### Fixed

- `Box` is fully qualified in the generated by-value receiver.
- Pinned the toolchain so `trybuild` snapshots match across environments.

## [0.1.0] - 2026-06-07

### Added

- Initial release: the `#[dyn_shim(TraitName)]` proc-macro generates a
  dyn-compatible shim trait from a non-dyn-compatible one, skipping `where Self:
  Sized` methods, with docs, README, LICENSE, and a GitHub Actions CI workflow.
